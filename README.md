# Important Codes

A collection of C and C++ programs covering the fundamentals: number theory,
arrays, matrices, functions, pointers, strings, and structures.

## Contents

Files are numbered roughly in the order the topics were learned:

| Range | Topic |
|-------|-------|
| 1–17  | Basics, conditionals, loops, patterns |
| 18–26 | Arrays |
| 27–34 | Matrices |
| 35–45 | Functions, pointers, `goto` |
| 46–49 | Sorting, strings, ASCII |
| 50–70 | Mixed practice problems |
| 71–79 | Matrix traversal (transpose, wave, spiral) |
| 80–84 | String pointers, shallow/deep copy |
| 85–94 | Structures, combinatorics, Pascal's triangle |

## Running a program

```bash
gcc 46_sorting.c -o sorting && ./sorting     # C
g++ 59_Factorial.cpp -o factorial && ./factorial   # C++
```
